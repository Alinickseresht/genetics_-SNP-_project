# Population Genetics: SNP Analysis

This project contains basic exercises for analyzing SNP (Single Nucleotide Polymorphism) data using Python.

## Directory structure

- notes/ : Conceptual notes
- scripts/ : Main scripts (VCF parsing, plotting, population comparison)
- datasets/raw/ : Raw VCF data
- datasets/processed/ : Processed outputs (frequency CSV files)
- practice/ : Small exercises (genotype counting, simple classification)
